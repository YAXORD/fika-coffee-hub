# ☕ Fika Coffee Hub

A modern, lightweight point-of-sale (POS) and management platform designed specifically for specialty coffee shops to handle rapid customer flows and product control.

The initial structure and UI landing page of this project were generated using **Lovable** (AI). This rapid prototyping allows me to focus on customizing the core functionality, improving the user interface, and preparing the application for backend integration.

## 🚀 Key Features

*   **Product Catalog:** Management of coffee types, brewing methods, and pastries.
*   **Quick POS Interface:** Designed for speed and efficiency during peak cafe hours.
*   **Responsive UI:** Seamlessly adapts to both counter-top tablets and mobile devices.

## 🛠️ Tech Stack

*   **Frontend:** React, TypeScript, Tailwind CSS.
*   **Tooling:** Vite, Lovable.

## ⚙️ Local Installation & Setup

To run this project locally, execute the following commands:

```bash
git clone [https://github.com/YAXORD/fika-coffee-hub.git](https://github.com/YAXORD/fika-coffee-hub.git)
cd fika-coffee-hub
npm install
npm run dev
````
